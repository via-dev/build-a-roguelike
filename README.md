# Let's Build a Roguelike: Odin Edition

This project is an Odin rewrite of the
"Let's Build a Roguelike" tutorial book
by Richard D. Clark, available
[here](https://users.freebasic-portal.de/rdc/tutorials.html). 
I made this project to learn how to make my
very own roguelike in Odin and I hope it will
also be useful for you.

You can access the original Freebasic source code
in the original link above or inside of the `freebasic-reference`
branch of this repo.
